Remote Sensing for Forest Monitoring @ AgroParisTech
===========================================

This repo hosts the lectures and tutorials on Remote Sensing for Forest Monitoring organized at AgroParisTech
as part of the [2026 ATHENS week](https://athensnetwork.eu/athens-programme.html).
It is under construction, and we expect some bugs and issues. 
Feel free to send feedback at romain dot thoreau at agroparistech dot fr.

You can look at the notebooks in a nicer format at https://rsfm.readthedocs.io/en/latest/.

This repo, in its format, is inspired by the [UvA Deep Learning Tutorials](https://github.com/phlippe/uvadlc_notebooks/tree/master).
